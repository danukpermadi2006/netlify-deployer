Info Keamanan & Cara Dapat Token

Aplikasi ini membutuhkan Netlify Personal Access Token. Ikuti langkah mudah ini untuk mendapatkannya:

  1. Buka halaman pengaturan token di app.netlify.com .
  2. Klik tombol New access token.
  3. Isi deskripsi (contoh: "Web Deployer") dan klik tombol Generate token.
  4. Salin (copy) kode rahasia yang muncul (Token ini hanya muncul sekali!).
  5. Tempelkan (paste) kode tersebut ke kolom Netlify Token di bawah ini.
Peringatan Keamanan: Fitur "Remember" hanya menyandikan token secara dasar (base64). Jika Anda menggunakan perangkat publik/warnet, JANGAN centang "Remember" dan pastikan untuk mengklik tombol Disconnect setelah selesai.
